# jewerly
Jewelry Workshop Website

An educational web development project featuring a fictional jewelry brand.
The website was designed and developed as an educational project. The brand and business concept are fictional and do not represent a real company.
Live demo: https://kuldaria.github.io/jewerly/

Features
* Responsive website layout
* Video background in the hero section
* Jewelry and gemstone galleries
* Navigation menu with dropdown
* Interactive FAQ section
* Scroll animations
* Contact form with client-side validation and simulated submission

Technologies
* HTML5
* CSS3
* JavaScript
* Google Fonts

Project structure
* index.html — main page
* try.css — styles
* scripts.js — interactive elements and page behavior
* *.jpg — images used on the website
* IMG_2630.MP4 — hero-section background video

Notes
This is a front-end educational project. The website is a demonstration and does not represent an actual jewelry store. The contact form simulates a successful submission but does not send data to a server or process real orders.
